Equipamentos Control iD

Linha iDClass

Seção Identificação:

  • Toogle de Ativação / Inativação: Altera o status atual do coletor:
    • ➡ Coletor Ativo / Em Operação.
    • ➡ Coletor Inativo / Fora de Operação.
  • Descrição: Exibe a descrição do coletor, conforme consta em seu cadastro.

  • Número de Série: Número de Fabricação / Série do equipamento, utilizado para identificação e realização de vínculo através do iGateway. Comumente vem anotado na parte inferior frontal do coletor.

  • Vínculo Unidade de Negócio: Define à qual unidade de negócio o coletor será vinculado.

Seção Configuração:

  • Interface de Comunicação: Define qual método de comunicação será utilizado pelo equipamento para interligação com o iGateway. No caso dos REP's iDClass, a opção é fixa no valor "TCP / IP".

  • Endereço IP: Endereço IP fixo do equipamento utilizado para identificação do coletor na rede e estabelecimento de conexão.

    Atenção

    Certifique-se de que o seu REP iDClass não está com a configuração de IP Dinâmico (DHCP) ativada nas configurações internas do equipamento, pois isso pode ocasionar a troca automática do Endereço IP, impedindo a identificação do coletor pelo iGateway.

  • Porta: Assim como o Endereço IP, é utilizada para estabelecimento de conexão com o equipamento na rede. No caso dos REP's iDClass a porta padrão é 443.

  • Usuário: Define o nome de usuário que será utilizado para acessar a interface web do equipamento.
  • Senha Login: Define a senha que será utilizada, juntamente com o nome de usuário, para acessar a interface web do equipamento.

iDFlex e iDFace:

Seção Identificação:

  • Toogle "Em Operação": Altera o status atual do coletor:
    • ➡ Coletor Ativo / Em Operação.
    • ➡ Coletor Inativo / Fora de Operação.
  • Descrição: Indica a descrição do coletor, que será exibida na lista de consulta, e no iGateway.
  • Número de Série: Número de Fabricação / Série do equipamento, utilizado para identificação e realização de vínculo através do iGateway.*
  • Vínculo Unidade de Negócio: Define à qual unidade de negócio o coletor será vinculado.

Informação

Para os equipamentos iDFace e iDFlex, o campo "Número de Série não está disponível para preenchimento, uma vez que este processo irá ocorrer de forma automática, a partir da primeira comunicação realizada pelo iGateway com o equipamento.

Seção Configuração:

  • Endereço IP: Endereço IP fixo do equipamento utilizado para identificação do coletor na rede e estabelecimento de conexão.

    Atenção

    Certifique-se de que o seu iDFace ou iDFlex não está com a configuração de IP Dinâmico (DHCP) ativada nas configurações internas do equipamento, pois isso pode ocasionar a troca automática do Endereço IP, impedindo a identificação do coletor pelo iGateway.

  • Porta: Assim como o Endereço IP, é utilizada para estabelecimento de conexão com o equipamento na rede. No caso dos REP's iDClass a porta padrão é 443.

  • Usuário: Define o nome de usuário que será utilizado para acessar a interface web do equipamento.
  • Senha Login: Indica a senha que será utilizada, juntamente com o nome de usuário, para acessar a interface web do equipamento.
  • UF (Fuso Horário): Define o fuso horário que será vinculado às marcações realizadas através do equipamento.
  • Local de Instalação (iGateway): Indica o local onde o equipamento está instalado, seja dentro ou fora das dependências da empresa (Ex.: Cozinha, Canteiro de Obras I, Sala de Descanso, etc.). Útil para filtrar, através da interface do nosso Agent de Comunicação iGateway, os coletores vinculados ao sistema com base no seu Local de Instalação.
    • + ➡ Botão para criação rápida de um Local de Instalação. Após criado, o Local é vinculado automaticamente ao coletor.
  • Seção "Habilitar Administrador: Permite incluir e configurar um usuário com Permissões de Administrador ao coletor:
    • Toogle de Ativação / Inativação: Habilita ou desabilita as configurações do usuário administrador.
      • ➡ Coletor Ativo / Em Operação.
      • ➡ Coletor Inativo / Fora de Operação.
    • Número do Identificador: Código do usuário administrador.
    • Senha: Senha do usuário administrador.

Atenção

Os dados e informações utilizados para preencher os campos na imagem acima são fictícios e apenas para fins de exemplo. Logo, não devem ser utilizados como base para preenchimento na sua conta!
